# Project Radar v3 operational budgets

Every network-backed v3 adapter is bounded by explicit configuration.

Budgets cover mapped entities, requests, pages, records, event files, event counts, repository releases, security-provider lookups, profile generation, graph size, alert matches, review entries, benchmark depth, and cache age. A stage that reaches its budget records partial coverage rather than silently implying completeness.

The default public workflow must fit within documented GitHub Actions runtime and provider rate limits. Operators may raise budgets for dedicated infrastructure, but resulting receipts must disclose the new coverage and runtime assumptions. Credentials, private data, and unbounded crawling are not accepted substitutes for explicit scope.

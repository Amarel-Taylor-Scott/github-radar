# Project Radar v3 license and upstream-terms policy

Each external source adapter must identify its authoritative upstream, documented endpoint, applicable terms or public-data license, attribution requirements, rate limits, and cache expectations before it is enabled.

The v3 repository republishes only normalized evidence necessary for discovery, auditing, and reproducibility. It does not mirror package contents, repository source code, complete provider databases, or proprietary reports. Links and provider identifiers are retained so consumers can inspect the authoritative source.

A source can be disabled independently when its terms, endpoint, or access model changes. Previously published evidence retains its provider and observation timestamp and must not be presented as current after freshness expires.

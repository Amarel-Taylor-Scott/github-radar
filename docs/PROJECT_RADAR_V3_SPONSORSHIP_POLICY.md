# Project Radar v3 sponsorship policy

Financial support, sponsorship, advertising, affiliate relationships, nominations, maintainer outreach, and commercial partnerships cannot create an automatic public ranking advantage.

Sponsored content, when introduced, must be visually and machine-readably separated from measured leaderboards. It must not alter repository evidence, catalog membership, score inputs, benchmark labels, review priority, or alert thresholds. Affiliations must be disclosed.

Revenue may support hosting, custom private catalogs, managed alerts, API service levels, research, consulting, or independently labeled editorial products. The open public methodology and evidence receipts remain auditable.

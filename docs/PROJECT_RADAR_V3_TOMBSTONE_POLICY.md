# Project Radar v3 tombstone policy

A repository that disappears from the current bounded discovery set is recorded as no longer discovered, not automatically deleted or abandoned.

A verified archival, deletion, transfer, rename, access restriction, or provider removal may produce a typed tombstone event with observation time, prior identifiers, source, and evidence class. Tombstones preserve links to prior snapshots and do not reuse stable identities for unrelated repositories.

Public profiles should distinguish current active records, archived records, moved records, and unavailable records. Removal from a leaderboard does not erase historical observations.

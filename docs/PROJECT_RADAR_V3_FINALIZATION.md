# Project Radar v3 finalization

The v3 implementation is complete when the feature branch passes its workflows, the integration pull request passes the full Python matrix, the change is promoted without rewriting v2 rankings, and the main-branch v3 workflow commits a validated production bundle.

The production receipt must confirm schema 3, source-commit agreement, project-count agreement with v2, typed signals, source-health receipts, graph and profile output, alert and feed parsing, SQLite integrity, API and SEO artifacts, shadow evaluation, benchmark metadata, and SHA-256 manifest verification.

Standalone mirror creation and GitHub Pages administration remain a separate administrative handoff because the connected integration cannot perform those operations.

# Project Radar v3 release notes draft

Project Radar v3 adds an evidence-aware intelligence layer above the validated v2 publication. It introduces bounded authoritative adoption and security adapters, release and optional event signals, grounded profiles, a typed knowledge graph, experimental shadow rankings and ablations, static alerts, relational and analytical exports, a read-only API, permanent project pages, and reproducible manifests.

The v2 production ranking remains unchanged. New external evidence is shadow-only by default, missing evidence remains missing, generated interpretation is separated from observed facts, and discovered repository code is never executed.

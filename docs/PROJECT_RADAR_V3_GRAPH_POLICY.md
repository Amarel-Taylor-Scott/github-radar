# Project Radar v3 graph policy

The v3 graph connects public technical entities and evidence without implying relationships beyond the labeled edge.

Supported node families include repositories, public owners or organizations, catalogs, topics, configured packages, releases, provider-scoped security records, profiles, and alerts.

Every edge declares its type, evidence class, provenance, source snapshot, and confidence or coverage where applicable. A configured package mapping means “this configuration associates the package with the repository”; it does not by itself prove trademark ownership or exclusive maintainership. A repository-owner edge reflects GitHub namespace metadata and does not establish employment or corporate control. Shared topics or catalogs are similarity evidence, not partnership evidence.

The graph is intended for navigation, search, aggregation, and transparent evidence traversal. Sensitive-person inference, private-data enrichment, and unsupported corporate or personal relationship claims are out of scope.

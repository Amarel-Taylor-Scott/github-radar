# Project Radar v3 profile policy

V3 project profiles are deterministic evidence summaries with a separately labeled interpretation layer.

## Observed facts

Observed facts can include repository metadata, catalog membership, topics, language, license identifier, timestamps, stars, forks, watchers, measured history, package mappings, package-registry evidence, release evidence, community-profile evidence, and provider-scoped security evidence.

## Generated interpretation

Interpretation may describe likely users, practical use cases, deployment patterns, integrations, limitations, or why a project surfaced. It must identify its template version and generation time, retain the source bundle, avoid claims about maintainer intent, and never overwrite observed repository facts.

## Prohibited profile claims

Profiles must not represent a ranking as proof of security, legality, commercial value, scientific novelty, maintainer endorsement, organizational ownership, or suitability for a particular regulated use.

Removing every generated profile must leave measured evidence and production rankings unchanged.

# Project Radar v3 catalog governance

Catalog definitions are versioned configuration, not hidden editorial rules.

Each catalog declares its title, scope, topics, keywords, negative terms, star thresholds, minimum record count, excluded project types, and source confidence. Custom search queries are bounded and documented. Catalog-local normalization prevents large ecosystems from setting the scale for smaller domains.

A catalog change should be tested for count stability, contamination, relevance, owner diversity, cross-domain diversity, benchmark performance, and historical continuity. New catalogs remain subject to the same source, evidence, safety, and publication gates as existing catalogs.
